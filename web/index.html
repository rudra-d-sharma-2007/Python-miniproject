How it works

01

Merge sort

The list is divided in half and merged back together in order — stable, predictable, O(n log n). Equal values end up side by side.

02

Adjacent scan

One forward pass compares neighbors. Any run of equal values becomes a duplicate with its occurrence count. Strictly O(n) — the whole point of sorting first.

03

Why not a hash set?

A set finds duplicates too, but it hides which order your data is in. Sorting gives you the report and the ordered data, on any comparable values.
